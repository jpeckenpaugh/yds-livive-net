# test-artifacts/

Generated by `tools/test-runner/run.mjs` (`npm run evidence`). **Ignored by git** — only this file is committed.

| Artifact | Contents |
|---|---|
| `result.json` | Machine-readable pass/fail per `AC-*` id, the milestone, and the exit code of each gate step. |
| `test.log` | Full captured output of every gate step, in order. |
| `<n>-<name>.png` | Numbered screenshots of each demonstrable behaviour, in the order a reviewer would exercise them. None yet: M1a has no UI. The browser job (Playwright) produces these at M1b. |

`result.json` shape:

```jsonc
{
  "milestone": "M1",
  "gate": [{ "step": "typecheck", "exitCode": 0, "ok": true }],
  "exitCode": 0,
  "acs": {
    "AC-DOM-09": { "status": "pass", "milestone": "M1", "tests": ["domain/variant-key.spec.ts"] },
    "AC-ENG-13": { "status": "unmapped", "milestone": "M3" }
  }
}
```

`status` is `pass`, `fail`, or `unmapped`. An AC id reported as passing with no evidence is treated as not passing (D1 §6), so `unmapped` is never a pass.
